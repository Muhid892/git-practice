# git-practice

## Useful Git Notes
- git init creates a new repository.
- git clone <url> copies a remote repository to your computer.
- git branch <name> creates a branch; git checkout -b <name> creates and switches to it.
- git add stages changes and git commit -m "msg" saves them.
- git push uploads commits; git pull downloads and merges remote changes.
- git stash temporarily saves uncommitted changes.
